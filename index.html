Everyone can play

UmpireRef caters for all players in the amateur sports ecosystem. Users are able to use our free mobile platform to both log and track match statistics. All data collected on the mobile platform can be synced to our web platform which offers premium services.

Officials

Using the mobile application, officials can log ongoing match events, view upcoming fixtures and track their performance over a season or tournament.

Organizers

Event organizers are able to set up, monitor and manage tournaments, including event registration and other various calculations.

Spectators

Fans can keep up to date with their favourite team or athlete using the mobile app. If you don't have a favourite team then discover upcoming fixtures in your location and show support.

Data Analytics

All interested stakeholders from athletes and officials to event organizers can input data onto our platform. This data can then be used through data analysis by various parties to observe various trends occurring in amateur sports that would otherwise go undetected e.g. identifying exceptional talent.
